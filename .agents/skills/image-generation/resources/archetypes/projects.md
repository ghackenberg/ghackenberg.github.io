# Visual Archetype: Projects (`preview.jpg`)

Project previews spotlight software systems, open-source tools, developer platforms, and cyber-physical testbeds.

## Visual Archetype: Isometric Tech Workbench Showcase

A high-tech 3D isometric cutaway workbench demonstrating the running system architecture, tangible hardware modules, and data layers.

## Avatar & Entity Rules
* **Avatar Inclusion**: **STRICTLY NO Georg avatar (Product Showcase)**.
* **Human Figures**: Strictly zero human figures or hands.
* **Rationale**: Spotlight is placed exclusively on the engineered artifact, software architecture, and tangible system components.

## Camera Framing & Setting
* **Perspective**: Elevated 30-degree isometric cutaway perspective.
* **Focal Target**: A centered high-tech industrial workbench or testing platform floating seamlessly in space.
* **System Visualization**: 3D holographic projection of the software system architecture, floating translucent data planes, or connected physical hardware modules with pulsing circuit traces.

## Environment & Palette
* **Environment**: Infinite dark slate coordinate grid canvas.
* **Palette**: Deep slate-black canvas (`#030712` / `#0b1329`) crisscrossed with subtle glowing coordinate grid lines in Brand Blue (`#3b82f6`) and cyan. Luminous accent LEDs highlighting active system components.
* **Format & Aspect Ratio**: `AspectRatio: "16:9"`, saved as `preview.jpg` in `src/content/projects/[project_id]/preview.jpg`.

## Canonical Prompt Template

```text
Elevated 30-degree isometric cutaway perspective of a futuristic high-tech engineering workbench showcasing [project name / core software functionality]. Centered on the workbench is an interactive 3D holographic projection of the software system architecture, floating translucent data planes, and connected physical hardware diagnostic modules with glowing circuit traces. The workbench floats seamlessly over an infinite dark slate coordinate grid canvas (#030712) with subtle illuminated cyan and brand blue (#3b82f6) grid lines. Cel-shaded mechanical precision, crisp ink linework, glowing status LEDs, immaculate modular layout, zero clutter. Strictly no people, no human characters, clean technological product showcase. ```
```
