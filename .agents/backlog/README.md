## Status-Definitionen
- `proposed`: Ausgearbeiteter Vorschlag, wartet auf Priorisierung.
- `planned`: Für die Umsetzung in einer der nächsten Tooling-Sessions eingeplant.
- `in-progress`: Aktuell in Entwicklung.
- `implemented`: Produktiv im Einsatz (registriert in `.agents/mcp_config.json` oder `package.json`).
- `deprecated`: Durch modernere Architektur abgelöst.
