voiceover: >
  Wie kann ein KI-Modell sicher auf lokale Daten zugreifen? 
  {cue:col-mcp-arch} Die Antwort ist MCP – das Model Context Protocol. MCP trennt die reine Sprachintelligenz 
  von der Ausführungsumgebung. 
  {cue:col-mcp-tools} Der Agent kommuniziert über ein standardisiertes JSON-RPC-Protokoll mit lokalen Servern: 
  einem Server für das Dateisystem, einem für Chrome DevTools und einem für die Google Search Console API. 
  Damit kann der Agent Fehler nicht nur beschreiben, sondern direkt im Code beheben.
